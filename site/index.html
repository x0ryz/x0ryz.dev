hakobu

Open source, Go, MIT

Deploys apps from GitHub to servers you own. Push to the default branch, and hakobu builds the new version and swaps it in with no downtime, behind a Cloudflare Tunnel, so the server needs no open ports.

  • Blue/green deploys with rollback, including the database
  • Postgres, Valkey and R2 storage per project
  • Encrypted backups that are test-restored after every upload
  • Sentry-compatible errors, logs and traces kept on your server
  • One binary with SQLite, rootless Docker, signed releases
